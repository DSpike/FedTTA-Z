# Performance Plots Comparison: Three Key Visualizations

## Overview
This document explains the differences between three performance evaluation plots generated by the system:
1. **`performance_comparison_annotated_Exploits_`** - Overall test set comparison
2. **`zero_day_performance_comparison_Exploits_`** - Zero-day samples only
3. **`base_model_performance_barchart_Exploits_`** - Base model standalone

---

## 1. Performance Comparison Annotated (`performance_comparison_annotated_Exploits_`)

### **Purpose:**
Compare **Base Model** vs **TTT-Adapted Model** on the **ENTIRE TEST SET** (mixed composition: Normal + Zero-day + Other attacks)

### **What it Shows:**
- **Side-by-side bar chart** comparing Base and TTT models
- **7 metrics**:
  1. Accuracy
  2. Precision
  3. Recall
  4. F1-Score
  5. **AUC-PR** (Primary metric for imbalanced data)
  6. **ZDR** (Zero-Day Detection Rate) ⭐
  7. **FAR** (False Alarm Rate) ↓ (lower is better)

### **Key Features:**
- ✅ **Performance improvement annotations** showing % change from Base to TTT
- ✅ **Complete test set** evaluation (40% Normal + 35% Non-zero-day + 25% Zero-day)
- ✅ **Overall system performance** assessment
- ✅ Shows how TTT improves the global model across all scenarios

### **When to Use:**
- Assess **overall IDS performance** on all traffic types
- Evaluate **TTT adaptation effectiveness** across the board
- Understand **trade-offs** between different metrics

### **Data Source:**
- `evaluation_results['base_model']` - FedProx aggregated global model
- `evaluation_results['adapted_model']` - TTT-adapted version
- Both evaluated on **`X_test, y_test`** (full test set)

---

## 2. Zero-Day Performance Comparison (`zero_day_performance_comparison_Exploits_`)

### **Purpose:**
Compare **Base Model** vs **TTT-Adapted Model** on **ZERO-DAY SAMPLES ONLY** (isolated evaluation)

### **What it Shows:**
- **Side-by-side bar chart** comparing Base and TTT models
- **5 metrics** (reduced set for zero-day-only context):
  1. Accuracy
  2. Precision
  3. Recall
  4. F1-Score
  5. **ZDR** (Zero-Day Detection Rate) ⭐

### **Key Features:**
- ✅ **Zero-day samples only** (25% of test set, filtered)
- ✅ **No AUC-PR** (excluded: not meaningful when all samples are attacks)
- ✅ **No FAR** (excluded: not meaningful when all samples are attacks)
- ✅ **Focused zero-day detection** capability assessment
- ✅ Shows sample count in title (e.g., "1,113 zero-day samples only")

### **When to Use:**
- Assess **zero-day attack detection** capability specifically
- Evaluate **TTT's impact on zero-day detection** only
- Understand **novel attack handling** performance

### **Data Source:**
- `evaluation_results['base_model']['zero_day_only']` - Base model on zero-day samples only
- `evaluation_results['adapted_model']['zero_day_only']` - TTT model on zero-day samples only
- Both filtered to **only zero-day attack samples** from test set

---

## 3. Base Model Performance Bar Chart (`base_model_performance_barchart_Exploits_`)

### **Purpose:**
Show **Base Model performance ONLY** (no comparison) as a standalone reference

### **What it Shows:**
- **Single bar chart** for Base Model only
- **4 core metrics**:
  1. Accuracy
  2. F1-Score
  3. Precision
  4. Recall

### **Key Features:**
- ✅ **Base model standalone** performance (before TTT)
- ✅ **Simplified metrics** (no AUC-PR, ZDR, FAR)
- ✅ **Visual reference** for baseline performance
- ✅ Shows what the FedProx aggregated global model achieves **before adaptation**

### **When to Use:**
- Establish **baseline performance** reference
- Quick overview of **FedProx global model** capability
- Compare against your **target performance thresholds**

### **Data Source:**
- `evaluation_results['base_model']` - FedProx aggregated global model
- Evaluated on **`X_test, y_test`** (full test set)
- **Before any TTT adaptation**
