**Type**: **Self-Supervised Learning**

## 🔍 **Why It's Self-Supervised (Not Unsupervised)**

### **Self-Supervised Learning Definition**:
- Model generates its own labels from the data
- Uses structure/patterns in the data itself
- Pseudo-labels are derived from model predictions

### **Your Implementation**:
```python
# Model generates pseudo-labels from its own predictions
query_pseudo_labels = unique_labels[query_pseudo_indices]  # From model's predictions
query_loss = F.cross_entropy(query_logits, query_pseudo_labels)  # Uses self-generated labels
```

**This is self-supervised** because:
1. ✅ Labels are **generated by the model** (not provided externally)
2. ✅ Uses **model's own predictions** as supervision signal
3. ✅ Leverages **data structure** (prototype-based classification)

3. **Adapts to specific test distribution** (not just generalizing)
